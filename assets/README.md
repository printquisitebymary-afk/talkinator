# TALKINATOR Assets

This folder should contain the following image files:

## Required Images

1. **header_wordmark.png** - The TALKINATOR logo/wordmark for the header (appears on all screens except the landing page)
   - Reference: Image 3 from Flowstep
   - Usage: Header component

2. **start_wordmark.png** - The TALKINATOR logo/wordmark for the landing/start page
   - Reference: Image 4 from Flowstep  
   - Usage: FrontPage component
   - Note: This is a larger, more prominent version of the wordmark

3. **block_bg.png** - The background image for the hero blocks
   - Reference: Image 5 from Flowstep
   - Usage: SearchScreen, SavedScreen, RecentScreen, TranslatorScreen
   - Note: This is the purple/pink gradient background with wavy lines

## Image Specifications

- Format: PNG with transparency support
- The code uses these images with `object-cover` and `opacity-80` for the block background
- The wordmarks should be sized appropriately for their containers (header: h-6, start page: w-80)
